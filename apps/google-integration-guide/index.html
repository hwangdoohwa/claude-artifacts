보안 주의

  • 클라이언트 보안 비밀번호(GOCSPX-로 시작)는 캡처, 채팅, 메신저에 절대 올리지 마세요. 검은 창에만 붙여넣습니다.
  • 실수로 노출했다면 Google Cloud 콘솔 → Google 인증 플랫폼 → 클라이언트에서 해당 클라이언트를 열고 새 보안 비밀번호를 추가한 뒤 예전 것을 삭제하세요.
  • "JSON 다운로드"로 받은 파일에도 비밀번호가 들어 있습니다. 공유 폴더나 메신저에 올리지 마세요.
  • 구글 비밀번호 입력, 2단계 인증, 권한 허용은 반드시 본인이 직접 하세요. 누가 대신 해 주겠다고 하면 거절하세요.
  • Claude가 일정 추가·메일 발송처럼 무언가를 바꾸기 전에는 확인을 요청합니다. 내용을 읽고 승인하세요.
